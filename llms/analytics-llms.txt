## What this index is not

- It is not an API. There is no baseURL, no OpenAPI, no authentication, no rate limits, no
  pricing, and no support channel attached to "Analytics" as an entity.
- The `.well-known` and `llms.txt` documents served at apievangelist.com belong to the API
  Evangelist profile, not to this index. See `well-known/analytics-well-known.yml`.
- Each provider listed under "Ecosystem" is profiled separately and independently; go there for
  contracts, scopes, security, rate limits and ratings.

## Categories

- Web Analytics — tracking website traffic and visitor behavior (Google Analytics, Plausible, Matomo, Umami, Swetrix, OpenPanel)
- Product Analytics — tracking user interactions within products (Mixpanel, Amplitude, PostHog, Heap)
- Mobile Analytics — mobile application behavior and attribution (Firebase, AppsFlyer)
- Customer Data Platform — collecting, unifying and routing customer data (Segment, mParticle, RudderStack, Snowplow)
- Business Intelligence — querying and visualizing analytics data (Looker, Tableau, Metabase, Redash)
- Event Streaming — high-throughput event ingestion (Apache Kafka, Amazon Kinesis, Confluent)
- Real-Time Analytics — real-time analytical query engines (ClickHouse, Apache Druid, Apache Pinot)
